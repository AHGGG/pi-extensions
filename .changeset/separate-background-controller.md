Extract background scheduling, settings, menus, pause/resume, and diagnostics into the optional pi-background-compaction companion. Expose a versioned prepared-compaction engine protocol while preserving ordinary foreground compaction, checkpoint compatibility, and tool replay. Existing background users must install the companion; it reads legacy opt-in settings without rewriting the core settings file.
